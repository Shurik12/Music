description: Подготовить PR в main из текущей ветки
---

Подготовь PR из текущей ветки в `main`.

- Заголовок — короткий, `type: краткое описание` (type: feat/fix/refactor/docs/chore).
- Описание — разделы: Summary, Changes (список), Testing (как проверить).
- Убедись, что `uv run main.py` запускается без ошибок.
- Перед PR запусти независимое ревью (`/review`); при наличии `blocker` — сначала исправить.

Push и создание PR выполни только после явного подтверждения человека — сначала покажи готовый текст заголовка и описания.
